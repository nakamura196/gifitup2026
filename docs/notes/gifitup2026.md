# GIF IT UP 2026 実験ノート

## 2026-10-15

- 応募作は3点に決めた: 国芳「みかけハこハゐがとんだいゝ人だ」(東京富士美術館, CC0)、栗本丹洲『千蟲譜』蝉 (NDL, PDM)、『新訂萬國全圖』(NDL, PDM)。鳥獣戯画 (TNM 模本, CC BY) は予備。
- 却下: 北斎『踊独稽古』の8場面の切り替え (動きに筋が無く、面白くない)。石渕家地球儀 (CC BY-NC のため規約外)。鳥獣戯画 (既に広くアニメ化され、絵に隠れた仕掛けが無い)。
- 判断の軸: 動きが、その絵自身の性質を明かすこと (寄せ絵なら、顎や手が別々の人であると分かる動き)。
- 規約 (gifitup.net/rules) に「未発表に限る」の定めは無い。応募作には主催者が CC BY 4.0 (元が SA なら同じライセンス) を付ける。念のため、このリポジトリの公開は応募後とする。
- 方針: 画像はリポジトリに入れず、IIIF の URL から取得する。マスクと作成プログラムを入れ、1つのコマンドで同じ GIF をビット単位で再現できるようにする。生成AIを画像に使っていないことの裏付けとする。

## 2026-10-15（夜）

- 地球儀はゆっくり回る版（640 px、1.87MB）に決めた。720 px でゆっくり回すと約 2.9MB になり、2MB に収まらない。回転のコマは 1 枚 40〜70KB かかり、GIF でいちばん重い。
- 蝉は v5 に決めた。背中が縦に割れるのに成虫が横向きに見えた原因は、丹洲が頭と胸を横に広く描いていること。割れ目に沿った細いすき間から見せ、縦に伸ばしてから広げることで解決した。本物らしさは追わない（絵が説明書きを演じるのが面白さ）。
- 国芳は、隠れていた体を補ってから動かす方針にした。補った場所は図に残し、応募時に申告する。
- 学び: 強いのは、元の絵そのものに仕掛けや不思議さがある作品（寄せ絵、羽化を説明する図譜、丸い世界を平らに描いた地図）。動きはその仕掛けを解き明かすために使う。仕掛けの無い名画を動かしても、驚きは生まれにくい（鳥獣戯画を予備にした理由）。

## 2026-10-15（応募の直前）

- 方針を変え、リポジトリを応募の前に公開した。AI の申告欄に URL を書き、審査員が「画素は元の資料のもの、AI はプログラムを書く道具」であることを自分で確かめられるようにするため。規約に「未発表に限る」の定めが無いので問題ない。
- AI の申告は YES とした。人手でも作れる種類の GIF だが、フォームが聞くのは「使ったか」であり、記入例にも「背景の切り抜き」「動きを作る」が挙がっている。マスク・補完・動きの組み立ては Claude Code が行った。失格になるのは「全部またはほとんどを生成 AI で作ったもの」だけ。
- 応募フォームの年齢・学校の欄は、6〜18 歳の部門にチェックしたときだけ現れる。
